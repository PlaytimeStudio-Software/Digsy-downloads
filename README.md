# Digsy downloads

Digsy is a cozy 2D digging and building game by Playtime Studio. This page holds the game's
downloads only; the source code is private.

## Installing

- **Windows:** if SmartScreen warns, choose More info > Run anyway.
- **Mac:** open the .dmg and drag Digsy to Applications. The first time, click Done on the warning,
  then System Settings > Privacy & Security > Open Anyway.
- **Android:** open the .apk on the phone and allow installing from this source. New versions
  install over the old one and keep your worlds.

Your worlds are saved on your device and are kept when you update.
